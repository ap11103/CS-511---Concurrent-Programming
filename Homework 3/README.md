The task is to implement various operations to support a shipping company in managing its cargo and logistics. The shipping company operates a fleet of cargo ships that transport containers between ports. Each port has a number of docks for loading and unloading containers.

Key Features
Ship Management:
Create and manage data structures to represent cargo ships, their containers, and their locations.

Port Operations:
Handle operations for ports, including loading and unloading containers. Each port consists of several docks, but the container's specific dock location is not tracked when containers are stored in a port.

Container Tracking:
Manage the states of containers, which can either be:

In transit on a ship
Located at a port
